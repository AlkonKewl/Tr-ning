        Ruck

        // allerede en styrke — vedligehold

        Din ruck-kapacitet er allerede god (~20 kg × 5 km på ~8:30/km). Ruck er en central soldaterfærdighed, men skal vedligeholdes og udvikles gradvist — ikke fylde så meget at det hæmmer løbet. Øg aldrig vægt, distance og tempo samtidigt. Prioritér i rækkefølgen: distance → terræn → pace → vægt til sidst.

        Hoftebælte spændt, vægt højt og tæt. Stabilt tempo — ikke nødvendigvis max effort. Terræn tæller mere end kilo.

        Uge A · søndag

        Langflex
        01Terrænmarch15–20 kg · 8–12+ km
        Vægt · 15–20 kgDistance · 8–12+ kmUnderlag · Skov · bakker
        Udførelse

        Roligere pace, varieret terræn, drik undervejs. Skift fodføring ved hotspots. Kan erstattes af jagt/terrænvandring.

        Note

        Ikke lang ruck hver søndag — i Uge B er søndag et langt roligt løb i stedet. Længere ruck cirka hver anden uge.

        Jeg presser ikke ruck-vægten mod 25–30 kg for træningens skyld. HJV kan også indeholde ruck, og det tæller med i den samlede belastning.

        Testkrav — udførelse
        • Lunges: vægtstang på skuldre; bagerste knæ maks 10 cm over gulv; ret ryg; kontinuerligt uden pause.
        • Dips: frithængende; ned til bagsiden af skuldrene er under albuerne; fuld lockout i toppen.
        • Kropshævning: overhåndsgreb; strakte arme i bund; hagen over stangen; kontinuerligt.
        • Dødløft: fødder inden for håndgrebet; ret ryg; fuld lockout i knæ og hofte; kontrolleret retur.
        • Burpees: fra stående til maven rører gulv (hænder fri) → hop op med knæ, hofte og skulder i lige linje.
        • Planken: albuer i skulderbredde; ret linje; ingen vugge; hovedet i naturlig forlængelse.

        Progression

        // pr. kategori

        [ LØB ] Løb

        • 1. Base & tolerance — frekvens og easy runs
        • 2. Intervaller — 5–6 × 3 min, flere reps før fart
        • 3. Tempo — 15–20 min tærskelarbejde
        • 4. Cooper-specifik — 400–800 m, når basen holder
        • Ikke fartprogression før underbenene tåler frekvensen

        [ RUCK ] Ruck

        • Vedligehold ~20 kg × 5–7 km
        • Distance → terræn → pace → vægt (til sidst)
        • Lang ruck cirka hver anden uge
        • Aldrig vægt + distance + tempo på én gang

        [ STYRKE ] Styrke

        • Progression via reps → RPE → vægt
        • Squat/dødløft: vedligehold ved RPE 7–8
        • Pullups/dips/lunges: relativ styrke op (+vægt)
        • Ingen 5×5 dødløft som standard

        [ TEST C ] Test C

        • Test de 5 øvelser hver 4.–6. uge
        • Log resultat og se niveau i tabellen
        • Cooper-test i samme kadence

        [ DELOAD ] Deload

        • Cirka hver 4. uge efter behov (Uge C)
        • Tidligere hvis HJV-ugen var hård
        • HJV-belastning tæller som reel træning
        08

        Principper & regler

        01

        HJV mandag tæller som træning i den samlede belastning.

        02

        Øg ikke ruck-vægt, distance og tempo samtidigt.

        03

        Byg løbetolerance før aggressiv fartprogression.

        04

        Ved læg/fod-irritation: reducér løbeintensitet før du fjerner al aerob træning.

        05

        Airbike kan midlertidigt erstatte hård kondition — men ikke al løb.

        06

        Rå styrke skal vedligeholdes, ikke maksimeres.

        07

        Pullups, dips, lunges og burpees er høj prioritet.

        08

        Deload efter behov — især efter hårde HJV-uger.

        09

        Ingen træning behøver være failure for at virke.

        10

        Robusthed + kontinuitet > hero workouts.

        [ PC ] Plate carrier

        • Gåtur / hundeluftning (1–2 × 20–40 min/uge)
        • Pushups, pullups, planke
        • HJV-specifik tilvænning
        • Ikke statisk kompression bare for at "have den på"

        [ CORE ] Core

        • Sideplanke · planke · hanging knee raises
        • Kort og konsekvent — ikke stor volumen

        [ GREB ] Greb

        • Loading pin hold · wrist roller
        • Understøtter ruck og pullups

        Dagens beslutning

        // simpel readiness — ikke diagnostik

        Grøn

        • Sovet rimeligt
        • Ingen nævneværdig smerte
        • Ben føles normale
        → Kør det planlagte pas.

        Gul

        • Træt efter HJV
        • DOMS
        • Dårlig søvn
        → Reducér volumen ca. 20–30 %, behold bevægelsen.

        Rød

        • Reel smerte
        • Ændret løbestil
        • Markant underbens-/ledirritation
        → Erstat impact/hård benbelastning med let træning eller hvil.
